# 응급 환자 골든타임 사수를 위한 지역 병원 병상 & 이동 동선 통합 제어
국립한국교통대학교 컴퓨터소프트웨어학과 26년도 캡스톤 디자인 G팀

## 1. 프로젝트 개요
본 프로젝트는 구급차 내 환자의 생체 신호와 현장 외상 임상 이미지를 수집하여 환자 중증도를 정밀 파악하고, 병원의 실시간 가용 자원 현황과 다각도로 연동하는 시스템이다. 프로젝트는 크게 두 가지 세부 하이브리드 파이프라인 시스템으로 구성됩니다.
1. 딥러닝 기반 다중 중증도 분류(Triage) 시스템: 현장의 구급대원이나 일반인이 스마트폰 카메라로 촬영한 외상 임상 이미지 및 환자의 안면/안구 데이터를 분석한다.
2. 동적 데이터 연동 기반 병원 라우팅 알고리즘: 판별된 중증도 점수와 지역 응급 의료기관의 실시간 병상 및 의료 자원(수술실, 전문의 가용 여부) 데이터를 결합하여 최적의 이송 병원을 매핑하고 최단 동선을 제어한다.

응급 의료 체계의 핵심인 '골든타임 확보'와 '이송 지연(응급실 뺑뺑이) 문제 해결'을 목표로 합니다.
## 2.주요 특징
- 다중 모달리티 데이터 처리 (Multi-Modal Data Pipeline): 현장 외상 및 질환 임상 이미지, 스마트폰 센서 기반의 오디오(기침 소리/음성 발음 뭉개짐), 실시간 안면 및 신체 관절 랜드마크 좌표 등 성격이 다른 이종(Heterogeneous) 멀티 모달 데이터를 유연하게 전처리하고 통합 처리하는 파이프라인제공
- 두 가지 독립적인 추론 및 분석 워크플로우
  - 경량 머신러닝 파이프라인: 안면 랜드마크 및 3D 신체 관절 좌표(MediaPipe/Yolo-pose 수치 데이터)를 기반으로 scikit-learning, XGBoost, LightGBM등을 활용하여 안면 비대칭도 점수 및 관절 왜곡 각도를 빠르게 계산하고 다단계 응급도 분류를 수행
  - 딥러닝 파이프라인: PyTorch 프레임워크와 이미지 분류 최적화 모델인 EfficientNet을 활용하여 외상 이미지(abrasions, bruises, cut, stab) 및 화상 단계(1 ~ 3도)를 정밀 분석
- 현장 신뢰성을 위한 해석 가능한 AI(XAI, Explainable AI)
- 재현성, 모듈성 및 온디바이스 최적화
  - 데이터 전처리, 모델 가중치 추론, 실시간 위치 및 병원 자원 데이터 매핑 과정을 기능별 스크립트로 철저히 모듈화하여 코드의 재사용성과 확장성을 극대화함. (특히, 모바일 흔들림이나 현장 조명 노이즈 환경에 대응하는 강력한 전처리 모듈을 탑재하여 현장 실전에 써도 손색없는 재현성 보장

# Python 가상환경(.venv) 설정 및 패키지 설치 가이드 (Windows)

프로젝트 실행 전, 로컬 PC 환경에 맞는 Python 가상환경을 생성하고 필요한 패키지를 설치하는 방법입니다.
## 1. 문제 원인
* 다른 OS(Mac/Linux) 또는 다른 PC에서 생성된 `.venv` 폴더는 경로 구조(`bin` vs `Scripts`)가 달라 Windows 환경에서 실행되지 않습니다. (`CommandNotFoundException` 발생)
* 가상환경은 Git으로 공유하지 않고 **각자의 로컬 PC에서 직접 생성**해야 합니다.

---

## 2. 해결 및 설치 방법

터미널(PowerShell)에서 프로젝트 루트 폴더(`Capstone-G-Team`)로 이동한 뒤 아래 순서대로 명령어를 실행합니다.

### 1단계: 기존 가상환경 삭제 (해당되는 경우)
이미 존재하는 `.venv` 폴더가 작동하지 않는다면 삭제 후 다시 생성합니다.
```powershell
Remove-Item -Recurse -Force .venv
```

### 2단계: 새 가상환경(`.venv`) 생성
Windows 환경에 맞는 가상환경을 생성합니다.
```powershell
py -m venv .venv
```
> **참고:** `py` 명령어가 작동하지 않으면 `python -m venv .venv`를 입력하세요.

### 3단계: 필수 패키지 설치 (`requirements.txt`)
생성된 가상환경의 파이썬을 이용해 `requirements.txt`에 명시된 라이브러리를 설치합니다.
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

---

## 3. VS Code 인터프리터 설정
패키지 설치 완료 후 VS Code에서 코드를 실행하려면 방금 만든 가상환경을 연결해야 합니다.

1. 단축키 `Ctrl + Shift + P`를 눌러 명령 팔레트를 엽니다.
2. **`Python: Select Interpreter`**를 검색해 선택합니다.
3. 목록에서 **`.\.venv\Scripts\python.exe`**를 선택합니다.

---

## 4. Git 업로드 시 주의사항 (`.gitignore`)
가상환경 폴더(`.venv`)는 용량이 크고 OS마다 구조가 다르므로 Git에 커밋하지 않도록 `.gitignore` 파일에 아래 내용을 반드시 추가해 주세요.

```text
# Python virtual environment
.venv/
venv/
```
